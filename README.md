# Project Documentation for 3D Body Simulation

## Introduction
This project aims to provide an interactive simulation of a 3D body.

## Installation Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/simonswordthi/sam-3d-body.git
   ```
2. Navigate to the project directory:
   ```bash
   cd sam-3d-body
   ```
3. Install the necessary dependencies:
   ```bash
   npm install
   ```

## Usage Guide
1. Start the application:
   ```bash
   npm start
   ```
2. Open your browser and go to `http://localhost:3000` to view the simulation.
3. Interact with the 3D body to explore its functionalities.
